# 信用风险预警项目 · 数据与领域层（zh_credit）

本目录是项目的**自建增量层**（100% 本人编写），对应 README 中的"数据与领域层"。
MARVIS 平台（marvis/ 目录）作为引擎原样保留，本目录负责：**中国数据获取 → 标签构建 → 特征工程 → 分析产出**。

## 模块规划

| 文件 | 功能 | 状态 |
|---|---|---|
| `data_fetch.py` | akshare 抓取 A股列表→财务指标（年报筛选）→清洗（金融剔除/选列）→CSV；断点续跑+限速重试 | ✅ 完成（5,468公司×7年） |
| `label_build.py` | 综合标签：首次亏损＋债券违约；时点对齐（T年财报→T+1年事件，防前视偏差） | ✅ 完成（正样本1,986） |
| `bond_issuer_map.py` | 标记"是否发债主体"（上市公司发债名单） | 待开发（W1） |
| `features.py` | 20+ 信用比率：杠杆/流动性/盈利/现金流质量/营运/成长/规模/趋势Δ | 待开发（W2） |
| `industry_map.py` | 申万行业映射 + 国企/民企属性 | 待开发（W3） |
| `warning_list.py` | 最新一期打分 → 预警清单 TOP50 | 待开发（W3） |
| `notebooks/` | 建模 Notebook（逻辑回归 + XGBoost），定义 RMC 契约变量 | 待开发（W2） |
| `output/` | 模型产物、评分卡刻度表、预警清单、报告 | 待开发 |

## 数据源结论（2026-08-19 实测）

- **akshare**：主方案。免费，A股财务数据可批量获取（`ak.stock_info_a_code_name()`、`ak.stock_financial_analysis_indicator()` 等）；
- **同花顺 iFinD 试用账号**：HTTP API 可用（macOS 免客户端），**但试用权限下财务数据返回 null（仅行情/交易日可用）**；token 有效期至 2026-09-11；`../tools/test_ifind.py` 已备好，将来换正式账号（学校/实习单位）改 `.ifind.env` 即可用；
- **tushare**：备用方案（akshare 接口变动时切换）。

## 样本与标签口径（核心设计）

- 样本：A股非金融上市公司（含发债主体），2019–2023 财报面板，约 3000+ 公司 × 5 年；
- 标签：综合"信用风险事件"（ST/违约/处罚/审计非标），事件窗口 [T+1年5月1日, T+2年4月30日]（年报披露滞后对齐）；
- 定位声明：模型输出风险排序与预警，非精确违约概率；城投/非上市主体不在样本，依赖基本面与政策判断——此局限写进报告。
