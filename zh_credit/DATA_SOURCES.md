# 数据资源地图（Data Sources Map）

> 调研日期：2026-08-19 ｜ 结论：**GitHub 无任何现成标签/特征数据集（10+组关键词全部 0 结果）**；
> akshare 提供大部分基础数据，缺失部分（审计意见、ST历史、违约名单）需自建或代理。
> 本文件记录每一项数据需求的"现有资源 → 用法 → 自建方案"。

## 二、GitHub 调研结论（无现成，别浪费时间再找）

10+ 组关键词检索，全部 total=0 或最高★8：
- china bond default dataset / ST stock history / shenwan industry csv / ownership state dataset / audit opinion china / financial distress label ...
- **结论：标签与特征构建在开源世界没有成熟实现——"数据+领域知识"密集型工作，自建是唯一路径，也是本项目差异化所在。**

## 三、akshare 可用接口清单（实测通过）

## 四、自建方案（排期）

| 数据 | 方案 | 排期 |
|---|---|---|
| 债券违约名单 v1 | 已知主要违约上市公司主体（地产+民企，约50-80家，code+首次违约年份）+ 联合资信报告补充 | W2 初 |

## 五、结论

**基础数据（财务/行业/属性）全部有免费现成接口——这是最大的"先参考"成果；**
**事件型数据（违约/ST/审计）无现成资源——自建，但用"学术共识代理标签（首次亏损）+ 小规模手工名单（违约）"组合，避免被名单整理拖慢主线。**
