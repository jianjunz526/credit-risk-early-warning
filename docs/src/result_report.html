一、模型区分能力

图1 ROC曲线：训练AUC 0.912 / 验证0.850 / 样本外0.885——三集无过拟合，区分度强
图2 KS曲线（样本外2024）：KS=0.639——最优切点处能分离64%的好坏分布差距（信贷行业优秀线0.4）
图3 样本外好坏样本的分数分布：出险公司集中在高概率区，正常公司集中在低概率区——分离清晰
读图结论：模型把"未来一年出险"与"正常"两类公司分得很开（AUC 0.885），且训练/验证/样本外指标接近——没有过拟合，能力真实。

二、模型学到了什么（特征与稳定性）

图4 特征重要性TOP15：ROE/EPS/ROA/净利率等盈利类霸榜——模型核心依赖"盈利质量"，与信用分析理论一致
图5 校准趋势：各年度实际坏率与模型平均预测概率走势一致（预测略偏保守），2019-2020年高风险期被模型准确捕捉
读图结论：模型不是黑箱玄学——它学的就是"盈利腰斩＋利润不变现"这一规律（IV排序、特征重要性、压力测试三个独立证据一致）。
