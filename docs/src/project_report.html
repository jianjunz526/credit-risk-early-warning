中国发债主体信用风险预警模型 — 项目报告

作者：章建军 ｜ 日期：2026年8月20日 ｜ 平台：基于开源 MARVIS-Agent v2.3.2（MIT）二次开发
数据：akshare / 同花顺 iFinD / 巨潮 ｜ 版本：v1.0（含审计修复）

1. 项目概述

1.1 目标

用 A股上市公司（含发债主体）财务数据构建信用风险事件预警评分，定位是信评/风控的量化初筛工具：对最新一期财报主体输出风险排序与预警清单，辅助信用研究的人工复核（"量化初筛＋基本面终审"）。

1.2 定位声明（诚实边界）

  • 模型目标是风险排序与提前预警，不输出精确违约概率的绝对断言；
  • 样本为"上市公司中的发债主体"；城投与未上市主体依赖区域财政与政策判断，不在量化模型范围；
  • 信用研究业界做法是"评级＋规则＋舆情＋人工复核"，本模型定位为其中量化筛选一环。

2. 数据

2.1 样本构建

项内容
样本5,468 家 A股非金融上市公司 × 2019–2025 年报 = 37,956 行面板
数据源akshare 财务指标接口（新浪源）；行业=巨潮证监会分类（覆盖89%）；实控人=同花顺 iFinD 批量接口（覆盖91%）

2.2 标签定义（综合信用风险事件）

  • 主事件：首次年度亏损（EPS 由正转负）——中国财务困境研究的通行代理（ST 触发条件为连续亏损），时点干净无前视偏差：T 年财报（T+1年4月30日可得）预测 T+1 年首次亏损；
  • 增强事件：债券违约（公开可验证的 A股违约主体名单，default_year == T+1 的行标正）；
  • 正样本 1,986（5.23%），年份分布均匀（每年 280–400）；
  • 学术依据：中国上市公司财务困境研究以 ST 为核心标志（无美国式破产制度），"首次亏损→连续亏损→ST"是标准恶化路径。

2.3 特征体系（49 个）

  • 水平特征 26 个：盈利（ROE/ROA/净利率/营业利润率）、偿债（资产负债率/流动比率/速动比率/现金比率/利息保障）、现金流质量（经营现金流/净利润、/营收、/负债）、营运（应收/存货/总资产周转）、成长（营收/净利/总资产增速）、每股（EPS/BPS）、规模（总资产对数）；
  • 趋势特征 Δ 6 个（关键指标同比变化——"趋势比水平更重要"）；
  • 缺失指示变量（缺失率>5% 的列）；
  • IV>0.02 筛选后 25–27 个入模；IV TOP：roe(0.99)、eps(0.98)、roa(0.95)、net_margin(0.60)——盈利类主导，符合信用分析先验。

3. 方法论

3.1 特征处理（手写实现，可现场讲原理）

  • 等频分箱（训练集拟合，缺失单独成箱，WOE +0.5 平滑防零箱）；
  • WOE/IV 计算（坏占比-好占比）×WOE 的 IV 公式；
  • 评分卡刻度：Score = Offset + Factor×ln(odds)，PDO=20、odds=1:1→600 分（LR 主模型输出可解释评分卡）。

3.2 双模型

模型定位测试集（2024）
WOE 逻辑回归可解释主模型（银行风控标准，输出评分卡）AUC 0.864 / KS 0.596
XGBoost平台投产验证模型（PMML 工程化、效果更优）AUC 0.885 / KS 0.639

  • 压力测试（按特征类别剔除）：盈利类剔除后 KS 0.632→0.106（Δ-0.526）——模型核心依赖盈利特征，与信用分析先验一致；偿债/现金流类贡献次要但真实。

核心结论：盈利与现金流质量的恶化是比杠杆水平更早、更强的预警信号。 杠杆类水平指标（资产负债率/流动比率）在出险前区分度弱——因为中国上市公司普遍在"报表层面"维持杠杆指标，而盈利与现金流的恶化先于违约发生。这解释了为何模型 IV TOP 全部是盈利类指标，也解释了压力测试中盈利类剔除后模型崩溃。

4.3 所有制维度

  • 民企风险率 6.5% > 国企 5.8% > 无实控人 4.3%；
  • 高风险组合：畜牧业民企 16.7%（正邦、雏鹰等养殖周期股）、钢铁国企 13.5%（行业周期）、地产国企 10.8%；
  • 联合资信统计：2025 年新增违约主体 69% 为民营企业——与本样本所有制结论方向一致。

6. 局限与展望（诚实声明）

  • 样本覆盖：仅上市公司（akshare 现存量主体），已退市主体缺失；城投/非上市发债主体不在范围——模型结论不可外推至城投债定价；
  • 标签代理：主标签为首次亏损（困境早期信号），与 ST/违约存在时间差；违约名单为公开可验证子集（累计 309 家违约主体中的 A股部分），非完整名单；
  • 财务粉饰：模型基于报表数据，无法识别报表粉饰与表外负债——需与舆情、审计意见、实地调研结合（这正是"量化初筛＋基本面终审"定位的原因）；
  • 行业漂移：地产出清期后，地产链风险权重可能下降，模型需按年度重训与 PSI 监控；
  • 展望：接入审计意见、舆情文本（NLP）、区域财政数据（城投扩展）作为 V2 增强。
